
# HL7 FHIR R4 Learning Lab

## About This Repository
This repository documents my independent hands-on learning and practical exercises in HL7 FHIR R4, healthcare interoperability, REST APIs, clinical terminology, and FHIR validation.

My professional background includes HL7 v2.5.1 immunization messaging, immunization information systems (IIS), and public health data standards. I have also completed FHIR training through the CDC Public Health Informatics Fellowship bootcamp.

## Learning Objectives
- Understand FHIR resources, elements, datatypes, and references.
- Create and inspect synthetic Patient, Observation, and Immunization resources.
- Practice FHIR REST API interactions using HAPI FHIR test environments.
- Explore Bundles, search, profiles, and implementation guides.
- Study terminology concepts including SNOMED CT, LOINC, RxNorm, CVX, and UCUM.
- Practice FHIR validation and interpret OperationOutcome responses.
- Prepare for the HL7 FHIR Foundational Implementer certification.
